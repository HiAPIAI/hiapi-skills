# HiAPI Seedream 5.0 Pro Skill

Repository: https://github.com/HiAPIAI/hiapi-seedream-5-0-pro-skill

Model: `seedream-5.0-pro`

Use this skill for Seedream 5.0 Pro text-to-image and reference-based image editing through HiAPI.

## Best For

- In-image text and signage
- Brush-calligraphy posters
- Photoreal portraits
- Consistency-preserving edits
- Multi-reference composites

## Install

```bash
npx -y github:HiAPIAI/hiapi-seedream-5-0-pro-skill -y
```

OpenClaw:

```bash
openclaw skills add https://github.com/HiAPIAI/hiapi-seedream-5-0-pro-skill
```
