# HiAPI HappyHorse 1.0 Video Skill

Repository: https://github.com/HiAPIAI/hiapi-happyhorse-1-0-video-skill

Model: `happyhorse-1-0`

Use this skill when the user wants lightweight text-to-video generation through HiAPI.

## Best For

- Short videos
- Lightweight video drafts
- Social media clips
- Ad concepts
- Quick video prototypes

## Install

```bash
openclaw skills add https://github.com/HiAPIAI/hiapi-happyhorse-1-0-video-skill
```

Manual install:

```bash
git clone https://github.com/HiAPIAI/hiapi-happyhorse-1-0-video-skill.git
```
